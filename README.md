# 🌐 Leya - Sleek and Minimal Single-Page Application

**Leya** is a sleek and minimal single-page application built with **React** and **TypeScript**, designed to serve as a practical example for developing responsive and efficient web applications. It emphasizes clean design, a user-friendly interface, and optimized performance, making it an ideal resource for practicing modern web development skills.

## ✨ Key Features

- 🎯 **Minimal Design**: A clean and intuitive interface that enhances user experience by keeping things simple and straightforward.
- 📱 **Responsive Layout**: Ensures seamless adaptation to various devices and screen sizes, providing accessibility across phones, tablets, and desktops.
- ⚡ **Efficient Performance**: Powered by React JS to deliver fast, smooth, and dynamic interactions.

## 🛠️ Technologies Used

- ⚛️ **React 18**: JavaScript library for building interactive user interfaces.
- 🔷 **TypeScript**: Strongly typed programming language for improved code quality and developer experience.
- 🎨 **Tailwind CSS**: Utility-first CSS framework for rapid and modern UI development.
- ⚡ **Vite**: Next-generation frontend tooling for faster development.
- 📦 **pnpm**: Fast, disk space efficient package manager.
- 📄 **HTML5 & CSS3**: The core web technologies for structuring and styling the application.

## 🎯 Purpose

Leya is a resource for developers aiming to:

- 🖌️ Learn **responsive design** and layout techniques.
- 🔄 Practice **single-page application (SPA)** architecture using React and TypeScript.
- 💡 Explore the benefits of clean, **minimal UI/UX** design principles.
- 🔷 Experience **type-safe development** with TypeScript.

## 🚀 Getting Started

To run this project locally, follow these steps:

### 📋 Prerequisites

Ensure that you have **Node.js** and **pnpm** installed on your machine.

- Node.js (v16 or higher)
- pnpm (v8 or higher)

If you don't have pnpm installed, you can install it globally:

```bash
npm install -g pnpm
```

### 🔧 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/fahadshahbaz/Leya-law.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd leya
   ```
3. **Install dependencies:**
   ```bash
   pnpm install
   ```

## ▶️ Running the Project

Start the development server:

```bash
pnpm dev
```

Build for production:

```bash
pnpm build
```

Preview production build:

```bash
pnpm preview
```

Run ESLint:

```bash
pnpm lint
```
